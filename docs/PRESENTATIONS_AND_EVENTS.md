# Add presentations and attended events

[Sign in to VIVO](https://vivo-fonda.hu-berlin.de/vivo/authenticate) with your
self-editor account and open your researcher profile.

## Add a presentation

1. Click **Add presentation**.
2. Choose the **Presentation format**: Talk, Invited talk, Poster presentation,
   Demo, Lecture, or Other presentation.
3. Enter the title. Reuse a listed presentation only for the same contribution
   at the same event. Check **Your role**:
   poster/demo → Presenter; talk → Speaker; lecture → Lecturer. Change it if needed.
4. Select the existing **Event**. If it is missing, enter its name and choose
   **New event type**. Leave the event empty if it does not apply.
5. Enter the presentation date and click **Create Entry**.

A talk at a seminar uses **Talk** or **Invited talk** as its format and the
seminar as its event. No DOI or publication is required.

## Add an attended event

Use this when you attended an event, whether or not you also presented.

1. Click **Add attended event**.
2. Choose **Event type**, such as Seminar, Workshop, or Conference.
3. Start typing **Event Name**. Select the existing event if listed; otherwise
   enter its name.
4. Enter your attendance dates and click **Save attendance**.

Check saved entries in your profile's **Events** tab: **presentations** or
**attended event**. Click an entry's edit control to correct it.

## Dates and shared events

- For one day, enter only **Start date**. Add **End date** for several days.
  Dates are optional; enter just the year if the exact date is unknown.
- Attendance and presentation dates are separate. Example: attend 1–7 June,
  present on 4 June. Attendance dates do not change the shared event's dates.
- Select the same existing event in both forms. Matching names alone do not
  combine separate event records.

## Published papers and posters

Add the published paper or poster through **Add / manage publications**:
[publication steps](PUBLICATIONS.md). Choose **Poster** for the poster document
and **Poster presentation** for presenting it. A DOI is optional.
